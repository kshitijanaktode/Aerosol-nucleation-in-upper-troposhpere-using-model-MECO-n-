# Aerosol-nucleation-in-upper-troposhpere-using-model-MECO-n-
VOC-driven aerosol nucleation is an important source of new particle formation in the tropical upper troposphere. Organic precursors from tropical forests can survive deep convection and contribute to aerosol formation in the UTLS. MECO(n), GMXe, and ISORROPIA 2 help simulate aerosol transport and SOA partitioning.
